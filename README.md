# exercism-solutions
A repo for backing up but also sharing my solutions on [Exercism](https://exercism.org/).

I like to learn new things and refine my current skills on my free time. I would also like to promote Exercism, a free education site for learning and practicing a variety of programming languages. Free education is an ideal that I align with so I'd like to share and use these kinds of resources if I can.
